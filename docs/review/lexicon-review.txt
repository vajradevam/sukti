# Sūkti lexicon — scholar review packet

**Please review in one sitting.** Every proposal below was written by a non-scholar implementation engineer. Nothing is claimed to be scholar-approved. Corrections should be made in `lexicon/lexicon.toml`; the CSV and this file are generated by `tools/gen_review.py`.

## What we ask you to check

1. **Spelling and inflection** of each canonical ITRANS form (right stem, right vibhakti, correct conjuncts, anusvāra/nasal conventions).
2. **IAST** transliteration accuracy.
3. Whether the chosen form is the clearest option for a programming concept, given the alternatives listed.
4. The **open grammatical questions** at the end.

Status key: `validated-by-tool` = transliteration/normalisation round-trip verified with Vidyut-lipi; `pending-scholar-review` = awaiting your judgement. Tool validation does **not** imply grammatical approval.

## Open grammatical questions for the scholar

1. Is `astu` (imperative 3sg of √as) idiomatic for a mutable binding, or is `bhavatu` preferable? Both are listed; we currently accept both.
2. Is `nitya` acceptable adjectivally for an immutable binding, or should it be `nityam` / `achalam`?
3. Are the imperative forms `virama`, `anuvarta`, `paTha`, `vada`, `Anaya`, `prakAshaya`, `utthApaya` correctly formed (dhātu, guṇa, endings)?
4. Is `doShe` (locative sg.) the right catch-clause marker, or would `doSham` (accusative) be more idiomatic? Same question for `ante`.
5. Are the seven kāraka labels (`kartA`, `karma`, `karaNa`, `sampradAna`, `apAdAna`, `adhikaraNa`, `sambandha`) correctly inflected as singular role names? We used nominative/accusative stems; should genitive forms be used instead?
6. Is `sambandha` a defensible extension for a genitive-style parameter, or should we use `ShaShThI`?
7. Are `pUrNA~nka`, `dashamalava`, `shabda`, `sUchI`, `kosha` acceptable modern technical terms for int/float/string/list/map? Is `koSha` merely a variant or a distinct form?
8. Is `tantu` a respectful and clear term for a lightweight task, given its existing use as "thread/strand" in textual traditions?
9. Are there any sandhi, conjunct or anusvāra conventions in the error messages that should be corrected for natural Sanskrit?
10. Which of the listed alternatives should replace the current form, if any? Please mark entries `scholar-approved` in the TOML after correction.

## Respect and scope note

The language deliberately does not use mantras, deity names or sacred verses in examples or tests. Classical sample texts are attributed and chosen respectfully. The design makes no claim that Sanskrit is inherently superior for computing; Pāṇinian ideas are used as *language semantics* with documented simplifications, not as a mystical argument.
